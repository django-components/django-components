# v1.0.0

django-components 1.0.0 is a stability release. Upgrading from 0.153.0 needs no code changes.

From this release on, code that uses the documented API keeps working on every 1.x release. django-components is now in maintenance mode: 1.x releases bring security fixes, bug fixes and support for new Django and Python versions, and new features go to [Citry](https://citry.dev/). Read [Versioning and support](https://django-components.github.io/django-components/docs/overview/versioning/) for what 1.x promises and how long each Django and Python version is supported.

#### Refactor

- Features that earlier releases said would be removed in v1 stay in 1.x. They keep working, and they are now scheduled for removal in 2.0.0, which is not planned.

- PyPI now lists django-components as "Production/Stable".
